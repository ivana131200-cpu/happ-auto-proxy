# 📦 Структура проекта

```

├── .github/
│   ├── workflows/
```

## 🚀 Быстрая навигация

### Для новичков
1. Прочитайте [README.md](README.md) - общий обзор
2. Следуйте [SETUP_GUIDE.md](SETUP_GUIDE.md) - настройка за 5 минут
3. Если проблемы - [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

### Для опытных
1. Клонируйте репозиторий
2. Настройте GIST_TOKEN в Secrets
3. Запустите workflow
4. Копируйте happ:// ссылку из HAPP_LINK.txt

### Для разработчиков
1. Изучите [main.py](main.py) - весь код там
2. Запустите [test_local.py](test_local.py) для тестов
3. Прочитайте [CONTRIBUTING.md](CONTRIBUTING.md) перед PR

### Для решения проблем
1. [FAQ.md](FAQ.md) - быстрые ответы
2. [TROUBLESHOOTING.md](TROUBLESHOOTING.md) - детальные решения
3. Создайте Issue если не помогло
