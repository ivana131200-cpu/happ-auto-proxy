# Changelog

Все заметные изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-01-XX

### Добавлено
- ✨ Полностью автономная система генерации happ:// ссылок
- 🤖 GitHub Actions workflow с автоматическим запуском каждые 6 часов
- 📦 Агрегация прокси из 5+ проверенных публичных источников
- 🧹 Автоматическая фильтрация и дедупликация серверов
- 🔐 Интеграция с Happ Crypto API для генерации зашифрованных ссылок
- 💾 Автоматическое обновление GitHub Gist с постоянным URL
- 📝 Автоматическое обновление README.md с актуальной ссылкой
- 🛡️ Обработка ошибок и таймаутов
- 📚 Подробная документация (README, SETUP_GUIDE, TROUBLESHOOTING)
- 🧪 Тестовый скрипт для локальной проверки (test_local.py)

## Типы изменений
- **Добавлено** (`Added`) - новый функционал
- **Изменено** (`Changed`) - изменения в существующем функционале
- **Устарело** (`Deprecated`) - функционал, который скоро будет удален
- **Удалено** (`Removed`) - удаленный функционал
- **Исправлено** (`Fixed`) - исправление багов
- **Безопасность** (`Security`) - изменения безопасности
