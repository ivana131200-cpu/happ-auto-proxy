# 🚀 Быстрый старт за 3 минуты

## Что вы получите

✅ Постоянная happ:// ссылка для Happ Proxy  
✅ Автообновление серверов каждые 6 часов  
✅ 100% бесплатно (GitHub Actions + Gist)  
✅ Zero maintenance после настройки  

---

## Шаг 1: Fork этого репозитория (30 сек)

1. Нажмите **Fork** в правом верхнем углу
2. Создайте приватный репозиторий (рекомендуется)

---

## Шаг 2: Создайте GitHub Token (1 мин)

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
2. **Generate new token (classic)**
3. **Права:** ✅ только `gist`
4. **Срок:** No expiration
5. **Скопируйте токен** (показывается один раз!)

---

## Шаг 3: Добавьте токен в Secrets (30 сек)

1. Ваш репозиторий → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret**
3. **Name:** `GIST_TOKEN`
4. **Value:** вставьте ваш токен
5. **Add secret**

---

## Шаг 4: Настройте разрешения (30 сек)

1. **Settings** → **Actions** → **General**
2. Прокрутите до **Workflow permissions**
3. ✅ **Read and write permissions**
4. **Save**

---

## Шаг 5: Запустите (30 сек)

1. **Actions** → **Auto Update Happ Subscription**
2. **Run workflow** → **Run workflow**
3. Дождитесь ✅ (обычно 1-2 минуты)

---

## Шаг 6: Получите ссылку (10 сек)

**Вариант А:** Откройте файл **HAPP_LINK.txt** в репозитории

**Вариант Б:** Откройте **README.md** → секция "🔗 Актуальная подписка"

**Вариант В:** В логах Actions найдите:
```
🎉 Ваша постоянная happ:// ссылка:
   happ://crypt5/XXXXX
```

---

## Шаг 7: Добавьте в Happ (30 сек)

1. Откройте приложение **Happ**
2. **"+"** → **"Добавить подписку"**
3. Вставьте `happ://crypt5/...` ссылку
4. **"Добавить"**

---

## 📝 Важные заметки

### Сохраните GIST_ID (опционально, но рекомендуется)

После первого запуска:
1. Откройте логи workflow
2. Найдите: `GIST_ID: a1b2c3d4e5f6...`
3. Скопируйте ID
4. **Settings** → **Secrets** → **New secret**
5. **Name:** `GIST_ID`, **Value:** ваш ID

Это предотвратит создание нового Gist при каждом запуске.

### Проверка автоматического обновления

Через 6 часов:
- **Actions** → должен появиться автоматический запуск
- В Happ нажмите **"Обновить подписку"**
- Список серверов обновится

## ❓ Проблемы?

### Ошибка "GIST_TOKEN not set"
→ Проверьте написание: должно быть `GIST_TOKEN` (заглавные буквы)

### Ошибка "403 Forbidden"
→ Токен просрочен или нет прав `gist` → создайте новый токен

### Workflow не запускается автоматически
→ **Settings** → **Actions** → **General** → "Allow all actions"

### Нет серверов в подписке
→ Подождите и попробуйте снова через 30 минут

**Подробные решения:** [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## 💡 Полезные команды

### Изменить частоту обновлений
Отредактируйте `.github/workflows/update.yml`:
```yaml
schedule:
  - cron: '0 */12 * * *'  # Каждые 12 часов вместо 6
```

### Добавить свои источники прокси
Отредактируйте `main.py`:
```python
PROXY_SOURCES = [
    "https://your-source.com/proxies.txt",
    # ... остальные
]
```

### Ручной запуск
**Actions** → **Auto Update** → **Run workflow**
