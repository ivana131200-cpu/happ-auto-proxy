# ❓ Часто задаваемые вопросы (FAQ)

Ответы на популярные вопросы о системе Happ Auto-Update.

---

## 🏗️ Общие вопросы

### Что это за проект?

Это полностью автономная система для автоматической генерации и обновления зашифрованных happ:// ссылок для приложения Happ Proxy. Работает 100% бесплатно на инфраструктуре GitHub без необходимости в VPS или выделенном сервере.

### Как это работает?

1. GitHub Actions каждые 6 часов запускает Python скрипт
2. Скрипт собирает актуальные proxy-серверы из 5+ публичных источников
3. Фильтрует дубликаты и невалидные записи
4. Кодирует в Base64 подписку
5. Обновляет GitHub Gist (постоянный URL)
6. Отправляет URL в Happ API
7. Получает зашифрованную happ://crypt5/... ссылку
8. Сохраняет ссылку в репозитории

### Почему нужна именно happ:// ссылка?

Happ использует шифрование для подписок. Обычные http:// ссылки не работают. API crypto.happ.su шифрует вашу подписку и выдает happ:// ссылку, которую понимает приложение.

## 💰 Стоимость и лимиты

### Действительно ли это бесплатно?

**Да, 100% бесплатно** для большинства пользователей:

- GitHub Actions: 2000 минут/месяц на Free плане
- Этот workflow использует ~2 минуты каждые 6 часов
- 2 мин × 4 раза/день × 30 дней = 240 минут/месяц
- Остается 1760 минут для других проектов

### Что если превышу лимит Actions?

Вы можете:
1. Уменьшить частоту обновлений (с 6 часов до 12 или 24)
2. Перейти на GitHub Pro ($4/мес, 3000 минут)
3. Использовать другой GitHub аккаунт

### Есть ли скрытые платежи?

**Нет.** Все компоненты бесплатны:
- GitHub Actions (в рамках лимита)
- GitHub Gist (неограниченно)
- Happ API (бесплатный)
- Источники прокси (публичные)

## 🔒 Безопасность и приватность

### Безопасно ли хранить токен в Secrets?

**Да.** GitHub Secrets:
- Зашифрованы AES-256
- Не отображаются в логах
- Доступны только workflow вашего репозитория
- Не могут быть прочитаны через API

### Кто видит мои серверы?

- **Gist приватный** - только вы (если не поделились ссылкой)
- **Репозиторий приватный** - только вы
- Happ API видит URL вашего Gist, но не содержимое

### Могут ли украсть мою подписку?

**Маловероятно:**
- Gist приватный по умолчанию
- RAW URL известен только вам и Happ API
- happ:// ссылка зашифрована

**Но если параноите:**
- Сделайте репозиторий приватным
- Не делитесь GIST_ID
- Регулярно обновляйте токен

### Безопасны ли публичные прокси-серверы?

**Нет, не на 100%:**
- Публичные серверы могут логировать трафик
- Могут быть скомпрометированы
- Используйте HTTPS сайты
- Не передавайте конфиденциальные данные

**Для безопасности:**
- Используйте HTTPS Everywhere
- Включите DNS-over-HTTPS
- Не вводите пароли через публичные прокси

## ⚙️ Технические вопросы

### Почему Python, а не Node.js/Go/Rust?

- Python предустановлен в GitHub Actions
- Простой и читаемый код
- Отличные библиотеки для HTTP (requests)
- Легко модифицировать

### Можно ли запускать локально?

**Да:**
```bash
# Установите зависимости
pip install -r requirements.txt

# Установите переменные окружения
export GIST_TOKEN="ваш_токен"
export GIST_ID="ваш_gist_id"  # Опционально

# Запустите
python main.py
```

### Можно ли деплоить на других платформах?

**Да, с модификациями:**
- **GitLab CI/CD**: замените `.github/workflows/` на `.gitlab-ci.yml`
- **Jenkins**: создайте Pipeline
- **Cron на сервере**: запускайте `main.py` через crontab
- **Heroku Scheduler**: добавьте задачу

### Сколько серверов обычно в подписке?

**Зависит от источников:**
- Обычно: 100-300 серверов
- После дедупликации: 50-200 уникальных
- Качество варьируется (многие могут быть мертвыми)

### Почему не все серверы работают?

**Публичные прокси живут недолго:**
- Блокируются провайдерами
- Перегружаются пользователями
- Закрываются владельцами
- Обновление каждые 6 часов помогает иметь свежие

## 📱 Использование с Happ

### Нужно ли обновлять ссылку в приложении?

**Нет!** Это главное преимущество:
- Добавляете happ:// ссылку один раз
- Серверы обновляются автоматически внутри приложения
- Не нужно генерировать новую ссылку каждый раз

### Как часто Happ обновляет подписку?

**Зависит от приложения:**
- Автоматически при открытии (обычно)
- При нажатии "Обновить подписку"
- Можно настроить в настройках Happ

### Можно ли использовать несколько подписок?

**Да:**
- Создайте несколько репозиториев
- Или модифицируйте скрипт для создания нескольких Gist
- Добавьте все в Happ

### Какие серверы лучше работают?

**Зависит от региона:**
- Европа: VLESS, Trojan обычно лучше
- Азия: Shadowsocks популярнее
- Тестируйте разные протоколы

## 🔧 Кастомизация

### Как добавить свои источники?

Отредактируйте `main.py`:
```python
PROXY_SOURCES = [
    "https://raw.githubusercontent.com/your/repo/main/proxies.txt",
    # ... добавьте ваши источники
]
```

**Требования к источнику:**
- Plain text или Base64
- Один сервер на строку
- Поддерживаемые протоколы: vless://, vmess://, trojan://, ss://

### Как изменить частоту обновлений?

Отредактируйте `.github/workflows/update.yml`:
```yaml
schedule:
  - cron: '0 */12 * * *'  # Каждые 12 часов вместо 6
```

### Как отфильтровать только определенные протоколы?

В `main.py` измените `SUPPORTED_PROTOCOLS`:
```python
# Только VLESS и Trojan
SUPPORTED_PROTOCOLS = ['vless://', 'trojan://']
```

### Как добавить webhook уведомления?

Добавьте в конец `main.py`:
```python
import requests

def send_notification(happ_link):
    webhook_url = "https://hooks.slack.com/..."  # или Discord
    requests.post(webhook_url, json={
        "text": f"Подписка обновлена: {happ_link}"
    })

# В main() после генерации ссылки:
send_notification(happ_link)
```

## 🐛 Проблемы и решения

### Workflow не запускается

См. [TROUBLESHOOTING.md](./TROUBLESHOOTING.md#workflow-не-запускается-автоматически)

### Все серверы мертвые

**Это нормально для публичных прокси.**

Решения:
1. Подождите следующего обновления (6 часов)
2. Запустите workflow вручную
3. Добавьте больше источников
4. Используйте платный VPN для критических задач

### Happ не видит серверы

1. Проверьте, что используете последнюю версию Happ
2. Обновите подписку в приложении (↻)
3. Удалите и добавьте подписку заново
4. Проверьте, что Gist обновлен (откройте RAW URL)
